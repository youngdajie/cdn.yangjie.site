核心能力

CDN 分发

静态资源托管在 GitHub，通过 EdgeOne Makers 配置分发，让访问更快、更稳。

双平台支持

同时支持 GitHub 与 CNB 两个平台，仓库与账号可以按需要自由选择。

本地化管理

基于 Go 的 Windows 桌面应用，把同一件事搬到本地，用原生性能重做一遍。

不只是图片

在图片之外，顺手把「不只是图片」这件事补上——更多类型的静态资源同样可以走这套流程。

关于这个项目

一句话概括：GitHub 储存 + EdgeOne Makers 分发，用一套 CDN 思路来托管静态资源， 仓库里放文件，边缘节点负责送达。

配套工具是一个基于 Go 的 Windows 桌面应用，支持 GitHub 与 CNB 两个平台。灵感来自 PicX （作者 XPoet）。

与 PicX 不同的地方在于思路：把同一件事搬到本地，用原生性能重做一遍， 并顺手补上「不只是图片」这件事。
